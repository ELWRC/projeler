# NightQueen Stopwatch

A small neon-themed stopwatch built with vanilla HTML, CSS and JavaScript.

## Features

- Start, stop and reset controls
- Millisecond display
- Responsive single-page interface
- Progressive Web App manifest
- Offline app-shell caching with a service worker

## Run

Open `index.html` through a local web server. Service workers require an HTTP(S) origin rather than opening the file directly from disk.

## Stack

`HTML` `CSS` `JavaScript` `PWA` `Service Worker`
